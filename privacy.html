mooni의 단어장 · 시행일 2026년 9월 27일

저장하는 정보

이 앱은 사용자가 직접 입력한 단어 카드(뜻, 표현, 첨부한 사진, 카테고리)와 복습·연습 기록만 저장합니다. 이름, 연락처, 위치 같은 다른 개인정보는 수집하지 않습니다.

저장 위치

  • 사용자 기기: 모든 데이터는 먼저 사용자 기기의 브라우저 저장소에 저장됩니다.
  • 사용자 본인의 Google Drive: Google 계정으로 로그인하면, 같은 데이터가 사용자 본인 Google Drive의 앱 전용 숨김 폴더에 저장되어 기기 간에 동기화됩니다.

이 앱에는 별도의 서버가 없습니다. 데이터는 사용자 기기와 사용자 본인의 Google Drive 사이에서만 오가며, 앱 제작자를 포함한 다른 누구에게도 전송되거나 공유되지 않습니다.

Google 계정 권한

Google 로그인 시 drive.appdata 권한만 요청합니다. 이 권한으로는 이 앱이 만든 앱 전용 폴더에만 접근할 수 있으며, 사용자의 다른 Drive 파일은 보거나 수정할 수 없습니다.

Google API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

데이터 삭제

  • 앱에서 카드를 삭제하면 기기와 Drive에서 함께 삭제됩니다.
  • Drive에 저장된 앱 데이터 전체는 Google Drive 설정 → 앱 관리 → mooni의 단어장 → "숨겨진 앱 데이터 삭제"로 지울 수 있습니다.
  • Google 계정 설정 → 보안 → 타사 앱 액세스에서 이 앱의 권한을 언제든 해제할 수 있습니다.
